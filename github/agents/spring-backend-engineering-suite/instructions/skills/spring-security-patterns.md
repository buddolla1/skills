# Skill: spring-security-patterns

## Purpose
Detect backend security risks in Spring Boot services.

## When To Use
Use this skill for controllers, filters, auth code, validation logic, and security-sensitive configuration.

## Instructions
- Check authentication and authorization gaps.
- Check for missing validation, hardcoded secrets, insecure config exposure, and unsafe deserialization.
- Check for excessive internal error detail exposure and weak access-control patterns.
- Reuse the security guidance from [quality-and-ops.md](../../../../instructions/topics/quality-and-ops.md) and [api-and-exceptions.md](../../../../instructions/topics/api-and-exceptions.md).

## Output
- Vulnerability
- Severity
- File
- Security risk
- Recommended fix
