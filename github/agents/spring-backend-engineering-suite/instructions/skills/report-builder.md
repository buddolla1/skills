# Skill: report-builder

## Purpose
Merge sub-agent output into one actionable engineering report.

## When To Use
Use this skill after all sub-agents finish.

## Instructions
- Merge duplicate findings.
- Group related findings by domain.
- Keep the final report concise but actionable.
- Always include file paths, issue summary, why it matters, and recommended fix.

## Output
- Consolidated markdown report
- Deduplicated findings
- Priority action plan
