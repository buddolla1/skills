# Skill: ddd-bounded-context-analysis

## Description
Evaluate bounded contexts, aggregate boundaries, domain language, and domain cohesion.

## When to use
Use this skill for domain-heavy services, modular monoliths, and distributed systems that claim DDD alignment.

## Instructions
- Identify bounded contexts.
- Check aggregate size and responsibility.
- Flag domain leakage across boundaries.
- Assess consistency of ubiquitous language.

## Output Format
- DDD Issue
- Severity
- Evidence
- Why It Matters
- Recommended Fix
