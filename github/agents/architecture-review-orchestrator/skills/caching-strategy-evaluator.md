# Skill: caching-strategy-evaluator

## Description
Evaluate cache placement, TTL design, invalidation strategy, and stale-data risk.

## When to use
Use this skill when the codebase uses in-memory caches, distributed caches, or cache annotations.

## Instructions
- Review cache key design and uniqueness.
- Check TTL selection and refresh behavior.
- Assess invalidation correctness.
- Flag stale-data and over-caching risks.

## Output Format
- Caching Issue
- Severity
- Evidence
- Risk
- Recommended Fix
