# Skill: api-maturity-check

## Description
Evaluate API consistency, contract stability, validation, versioning, and response discipline.

## When to use
Use this skill when reviewing public endpoints, request/response models, and client-facing contracts.

## Instructions
- Assess endpoint naming and semantics.
- Review payload stability and validation strength.
- Check backward compatibility and versioning discipline.
- Flag poor error contracts or leaky abstractions.

## Output Format
- API Maturity Issue
- Severity
- Evidence
- Client Impact
- Recommended Fix
