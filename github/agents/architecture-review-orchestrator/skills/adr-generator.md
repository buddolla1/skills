# Skill: adr-generator

## Description
Generate concise Architecture Decision Record entries from validated findings.

## When to use
Use this skill when the review requires durable decision capture for significant architectural tradeoffs.

## Instructions
- Summarize the decision.
- Capture context, options, and consequences.
- Keep ADRs short and decision-oriented.

## Output Format
- ADR Title
- Status
- Context
- Decision
- Consequences
