# Skill: observability-checklist

## Description
Evaluate logging, metrics, tracing, health checks, and operational readiness.

## When to use
Use this skill when reviewing production readiness or incident-debuggability.

## Instructions
- Review log quality and correlation IDs.
- Check metrics and trace coverage.
- Assess health/readiness signal quality.
- Flag missing operational visibility.

## Output Format
- Observability Issue
- Severity
- Evidence
- Operational Risk
- Recommended Fix
