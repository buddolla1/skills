# Skill: c4-diagram-generator

## Description
Generate Mermaid-based C4-style diagrams for context, container, component, and flow views.

## When to use
Use this skill when the review needs architecture diagrams that communicate structure and relationships clearly.

## Instructions
- Prefer concise, readable Mermaid diagrams.
- Align diagram labels with actual repository terminology.
- Keep component boundaries explicit.
- Generate diagrams that support the final report.

## Output Format
- Diagram Name
- Mermaid Block
- Notes
