Agent Skills

Skills Overview

A presentation-ready summary of Agent Skills, how they work, why they matter, and how they are structured for reusable AI workflows.

Executive Summary

Agent Skills are a portable, open format for adding specialized capabilities, workflows, and reference material to AI agents on demand.

Each skill is a self-contained directory centered on SKILL.md. The file defines the skill's purpose, when it should activate, and how the agent should execute it.

Skill Structure

skill-name/
├── SKILL.md
├── scripts/
├── references/
├── assets/
└── ...

How Skills Work

1
Discovery
The agent loads only the skill name and description.
2
Activation
When the task matches, the agent loads the full SKILL.md.
3
Execution
The agent follows the instructions and loads supporting files only when needed.

Why Skills Matter

  • Clear intent for both humans and agents
  • Better reuse across many tasks and agents
  • Portable files that are easy to version and share
  • Extensible delivery through code, examples, and references
  • Consistent execution for complex workflows

How To Use Skills

Start with relevance
Use the skill name and description to confirm it matches the task.
Load on demand
Open the full SKILL.md and supporting files only when the workflow requires them.

When a skill provides scripts or templates, reuse them instead of rebuilding the process manually.

Skills vs Custom Instructions

Area Agent Skills Custom Instructions
Purpose Specialized capabilities and workflows Standards, conventions, and guidelines
Content Instructions, scripts, examples, resources Instructions only
Scope Task-specific and loaded on demand Usually always applied
Portability Open standard across compatible agents More tool-specific

Use skills for reusable capabilities. Use custom instructions for project rules, coding conventions, and review preferences.

VS Code Considerations

Discovery paths
VS Code can discover skills in project and personal locations such as .github/skills/, .claude/skills/, and .agents/skills/, plus matching user-level paths.
Invocation
Skills can surface as slash commands in chat. Frontmatter options like user-invocable and disable-model-invocation control whether a skill is visible in the menu or loaded automatically.

Specification Highlights

A skill is a directory containing SKILL.md, with optional scripts/, references/, and assets/ folders.

Frontmatter
name, description, optional license, compatibility, metadata, and allowed-tools.
Principles
Keep the main file concise, load resources on demand, and validate the skill before publishing.

Examples

Valid names

pdf-processing, data-analysis, code-review

Invalid names

PDF-Processing, -pdf, pdf--processing

Good description

Extracts text and tables from PDF files, fills PDF forms, and merges multiple PDFs. Use when working with PDF documents or when the user mentions PDFs, forms, or document extraction.

Poor description

Helps with PDFs.

Using Scripts

Skills can use one-off commands directly in SKILL.md or bundle reusable logic in a scripts/ directory.

One-off commands
Use existing tools when they already solve the job well, such as package runners or language CLIs.
Bundled scripts
Use reusable scripts when the workflow is complex enough to benefit from tested logic and predictable behavior.
  • Keep scripts self-contained or document dependencies clearly
  • Avoid interactive prompts
  • Provide concise --help output
  • Prefer structured output such as JSON or CSV
  • Separate diagnostics to stderr and data to stdout

Assets Examples

The assets/ directory is for static resources such as templates, diagrams, images, lookup tables, and schemas.

Valid
assets/report-template.md
assets/architecture-diagram.png
assets/field-map.json
Invalid
assets/scripts/extract.py
assets/references/spec.md
assets/README.txt when used as reference text

References

The references/ directory stores supporting documentation, rules, or checklists that the agent reads when it needs deeper guidance.

Repository Context

This repository’s top-level SKILL.md is the index for available skills. Each folder contains a specialized skill for areas such as documentation, testing, Java, Spring Boot, React, SQL, and validation.

Takeaway
Skills package expertise into a reusable format and keep agent context efficient through progressive disclosure.

Key Takeaways

  • Skills package expertise into a reusable format.
  • Progressive disclosure keeps agent context efficient.
  • SKILL.md is the core contract for each skill.
  • Scripts, references, and assets extend the skill without cluttering the main instructions.
